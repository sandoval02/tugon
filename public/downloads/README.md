# Downloads folder

Only the iPhone build lives here: put it as `tugon.ipa` (built on a Mac / Codemagic with
`codemagic.yaml`). Until the file exists, its button shows "Coming soon" automatically.

The Android APK is **not** stored here. It is over 100 MB, so it is published as a GitHub Release
asset named `tugon.apk`; see "Publishing a new app version" in the main README.
